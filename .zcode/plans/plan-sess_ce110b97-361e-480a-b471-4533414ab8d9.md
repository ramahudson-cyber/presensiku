### Fase 3 — Bersihkan `src/index.css`

**3.1 Hapus dead CSS** (line 38-41):
```css

```

**3.2 Hapus dark variants** (line 254-268):
- `.dark .professional-ambient-bg` dan `.dark .professional-grid-bg` (selector mati)

**3.3 Ubah `html:not(.dark)` → root** (line 297+):
Semua blok `html:not(.dark) { ... }` (~250 baris) → bongkar pembungkus, angkat rule ke scope global karena `.dark` sudah mustahil aktif:
- `html:not(.dark) .design-card` → `.design-card`
- `html:not(.dark) .design-input` → `.design-input`
- dst untuk semua `html:not(.dark) .X` di file

Variable `--bg-page`, `--bg-card`, dll di block `html:not(.dark)` → pindah ke `:root` atau global selector.

**3.4 `html:not(.dark) .professional-ambient-bg` & `.professional-grid-bg`** (line 279-292) → angkat ke global juga.

**3.5 Sidebar block** (line 541-572):
- `.dark .sidebar-gradient { ... }` → hapus
- `html:not(.dark) .sidebar-gradient { ... }` → `.sidebar-gradient` (langsung)

**3.6 Hapus `--color-obsidian`, `--color-onyx`, `--color-true-black`** dari `@theme` block (line 8, 9, 14) — tidak dipakai lagi setelah semua `bg-obsidian`/`bg-onyx`/`text-pure-white` di dark usage dihapus. ### Risiko & Mitigasi

| Risiko | Mitigasi |
|--------|----------|
| Ada `dark:` class yang ke-detect Tailwind v4 dan warning | Tailwind v4 silent-skip unknown utilities, build tetap jalan. Verified tidak ada error blocking. |
| Hex hardcoded `#000000` di EmployeeDashboard bawah hero bentrok dengan light palette | Ganti ke `#0F172A` (text-primary light token) |
| localStorage `theme=dark` user lama bikin flash putih | `removeItem` di main.jsx sebelum render |
| AdminLayout `bg-[#05020b]` di non-admin path bentrok | Admin path dominan, ganti ke `bg-slate-50` agar konsisten |
| `html:not(.dark)` rewrite salah → styling global rusak | Diff per blok: copy rule ke selector global, hapus prefix `html:not(.dark) ` |
