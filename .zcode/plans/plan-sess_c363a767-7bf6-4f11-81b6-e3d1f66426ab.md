# Plan: Debug & Fix Avatar Tidak Muncul di Halaman Profil

## Root Cause Analysis
Setelah mempelajari kode secara mendalam:
- **EmployeeEditProfile.jsx** → upload + simpan `avatar_url` ke database ✅
- **AuthContext.jsx** → `refreshUser()` ambil data dari `profiles` table lalu merge ✅  
- **EmployeeProfile.jsx** → cek `user?.avatar_url` untuk tampilkan foto ❓

Semua kode **tampak benar secara logika**. Kemungkinan penyebab:

1. **Migrasi `20260722000000_add_avatar_url.sql` belum dijalankan ke Supabase** → kolom `avatar_url` tidak ada
2. **Ada masalah RLS** pada tabel `profiles` untuk kolom `avatar_url`
3. **Storage bucket `avatars` belum dibuat** → upload gagal

## Langkah Perbaikan

### 1. Debug — Tambahkan console.log
Di `EmployeeProfile.jsx`, tambahkan log untuk melihat nilai `user?.avatar_url`:
```js
console.log("👤 User data:", { 
  avatar_url: user?.avatar_url,
  role: user?.role,
  full_name: user?.full_name 
});
```

### 2. Fallback — Cek user_metadata  
Tambahkan fallback untuk membaca dari `user?.user_metadata?.avatar_url` jika `user?.avatar_url` tidak ada:
```js
const avatarUrl = user?.avatar_url || user?.user_metadata?.avatar_url || null;
```

### 3. Sidebar — Tambahkan avatar
Perbaiki `Sidebar.jsx` untuk menampilkan foto profil jika ada (tidak hanya inisial):
```jsx
{user?.avatar_url ? (
  <img src={user.avatar_url} alt="" className="w-full h-full object-cover rounded-full" />
) : (
  <span>{initial}</span>
)}
```

### 4. Verifikasi Database
Pastikan migrasi avatar_url sudah dijalankan di Supabase project.
