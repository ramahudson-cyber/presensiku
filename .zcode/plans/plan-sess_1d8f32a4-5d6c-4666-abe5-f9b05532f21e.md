## Sidebar logo card — warna welcome screen

### Konteks
User minta card logo + nama "Presensiku" di sidebar pakai warna seperti welcome screen:
- Welcome bg: `linear-gradient(160deg, #BF00FF 0%, #9900CC 30%, #660099 70%, #33004D 100%)`
- Logo pin: putih. Wordmark "PRESENSIKU": putih, `letter-spacing: 0.3em`
- Sidebar sekarang: kotak gradient kecil + nama `text-pure-white` (di admin-light ke-override jadi hitam — masalah)

### Files

1. **`src/index.css`** — blok baru setelah `.s-logo-pin`:
```css
.sidebar-brand {
  background: linear-gradient(135deg, #BF00FF 0%, #9900CC 32%, #660099 70%, #33004D 100%);
  box-shadow: 0 10px 28px -10px rgba(155,0,255,0.5), inset 0 1px 0 rgba(255,255,255,0.14);
}
.sidebar-brand-title { color: #fff; letter-spacing: 0.12em; }
.sidebar-brand-sub { color: rgba(255,255,255,0.72); }
```
Custom class → tidak kena `.admin-light .text-pure-white { color:#0f172a !important }`.

2. **`src/components/Sidebar.jsx`** — header logo:
- Satu card `rounded-2xl sidebar-brand px-3.5 py-3 flex items-center gap-3` di area p-5
- Isi: `.s-logo-pin` SVG (animasi sekarang tetap), `h1` → `sidebar-brand-title` "PRESENSIKU" (uppercase, putih), tagline `sidebar-brand-sub` (putih 72%)
- Bobol: kotak `.bg-gradient-to-br from-electric-violet to-deep-indigo` dihapus — card sudah ungu; SVG langsung di card
- Tombol X tetap di kanan, di luar card (class `border-gradient` X)

3. **`admin-light-preview.html`** — update `.s-badge` + nama sesuai card di atas
